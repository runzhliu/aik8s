# Kubernetes Flow Control Diagrams

The three diagrams are mechanism explanations or calculation examples under explicit assumptions, not cluster screenshots or stress test results. They use MiniMax M3's light color layout, Hiragino Sans GB for Chinese, Helvetica Neue for English/numbers, and bold for key numbers.

| Image | Purpose | Basis |
| --- | --- | --- |
| `01-three-layers.png` | Distinguish governance locations for API, task, and inference requests | Kubernetes APF, Kueue/Volcano, Envoy Gateway official documentation |
| `02-apf-request-path.png` | Explain classification, concurrency budget, and queuing/rejection | APF and flowcontrol v1 API definitions |
| `03-rate-and-concurrency.png` | Explain the relationship between RPS and in-flight concurrency | Steady-state relationship N=λW; assume 20 req/s, average durations 0.2, 2, 10 seconds |

The desktop version is 1200×675; the same-named `-mobile.png` is an independently rearranged 720×1080 mobile version, switched via the picture element in the body on narrow screens, to avoid directly shrinking multi-column diagrams. All text and numbers in the diagrams are generated by code, and no generative image techniques are used to draw technical information.

Reproduction command (at repository root):

```bash
.venv/wechat/bin/python scripts/generate_kubernetes_flow_control_visuals.py
```

Source code: `scripts/generate_kubernetes_flow_control_visuals.py`. Depends on Pillow and the Chinese and English fonts declared in the script. Before publishing, check the original images, display at mobile width, and text boundaries; colors in this set of diagrams represent flow/emphasis, not inference engine performance.
