# Diagrams for Optimizing a 10,000-Node Kubernetes Cluster

These diagrams are deterministically generated by `scripts/generate_large_scale_kubernetes_optimization_assets.py` and are uniformly 1200×675, 16:9 light-colored horizontal images:

- `control-plane-pressure.png`: Control plane pressure model. The 1,000 Lease updates/second shown in the diagram is an arithmetic value calculated for 10,000 nodes using the default 10-second lease renewal interval, not a stress test result.
- `ten-thousand-node-choice.png`: Decision boundaries among multi-cluster, managed ultra-large-scale, and customized single-cluster architectures.
- `etcd-optimization-loop.png`: Execution order of etcd load reduction, resource isolation, maintenance, recovery, and sharding.

The mechanisms in the diagrams reference the official Kubernetes and etcd documentation; enterprise cases and applicable boundaries are cited item by item in the main text. The images do not contain production environment addresses, accounts, or internal configurations.
