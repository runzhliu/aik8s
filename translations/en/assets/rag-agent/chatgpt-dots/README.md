# ChatGPT Dots Schematic Diagrams

Both diagrams are deterministically generated by `scripts/generate_chatgpt_dots_assets.py`, with dimensions of 1200×675.

- `capability-map.png`: Capability relationships compiled based on official Dots documentation, not a server-side implementation diagram.
- `kubernetes-integration.png`: Integration recommendations for enterprise read-only queries and approval-based changes, not a deployed system or functional test.

Uses the light layout of existing technical diagrams, with Hiragino Sans GB and Helvetica Neue fonts. The diagrams contain no real accounts, internal addresses, credentials, or experimental results, and are not product interface screenshots.

Public sources:

- https://learn.chatgpt.com/docs/dots
- https://learn.chatgpt.com/docs/dots/computers-and-apps
- https://developers.openai.com/plugins/concepts/plugins
