# 多集群稳定性文章配图

两组图均为本文建议方案的架构示意，不是企业内部架构或生产测试数据。

| 图 | 用途 | 输出 |
| --- | --- | --- |
| fleet-boundaries | 展示中央策略、分组预算与集群本地执行的边界 | 1200×675 桌面图、720×1080 手机图 |
| rollout-gates | 展示假设 300 集群的分阶段发布及停止条件 | 1200×675 桌面图、720×1080 手机图 |

源代码：`scripts/generate_fleet_reliability_visuals.py`。字体与颜色复用 Kubernetes 流控文章的绘图辅助函数。假设批次为 2、8、30、60、200，互不重叠，总数 300；最后一组仍分为小批执行。所有图均明确标注“参考设计”或“假设算例”。
