# GPU Notebook platform evolution figures

The three article figures are generated by `scripts/generate_gpu_notebook_figures.py`.

Logo sources:

- JupyterHub: `jupyterhub/jupyterhub`, `docs/source/_static/images/logo/logo.png`
- code-server: `coder/code-server`, `src/browser/media/favicon-dark-support.svg`

The product names and logos remain trademarks of their respective owners. They are used here only to identify components in the architecture diagrams.

Regenerate the figures with:

```bash
.venv/wechat/bin/python scripts/generate_gpu_notebook_figures.py \
  --output-dir docs/assets/practices/gpu-notebook-platform-evolution \
  --logos-dir docs/assets/practices/gpu-notebook-platform-evolution/logos
```
