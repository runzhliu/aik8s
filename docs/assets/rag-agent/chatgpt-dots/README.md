# ChatGPT Dots 原理图

两张图均由 `scripts/generate_chatgpt_dots_assets.py` 确定性生成，尺寸为 1200×675。

- `capability-map.png`：基于官方 Dots 文档整理的能力关系，非服务端实现图。
- `kubernetes-integration.png`：企业只读查询与审批变更的接入建议，非已部署系统或功能实测。

采用现有技术图表的浅色布局、Hiragino Sans GB 与 Helvetica Neue 字体。图中没有真实账号、内部地址、凭据或实验成绩，也不是产品界面截图。
