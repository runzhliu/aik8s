# vLLM 实测结果（2026-08-15，MTP A/B 更新于 2026-08-17）

环境：单张 NVIDIA L20（46,068 MiB）、`vllm/vllm-openai:v0.26.0-cu129`、
Qwen3.8-27B-FP8、TP=1、32K、FP8 KV。day0 基线关闭 MTP，后续在相同环境
完成 MTP 1/2/3 Draft Token A/B。

本目录保留两组口径：不带 `-r1` 的 JSON 是最初从服务 Pod 通过 loopback
得到的 day0 基线；带 `-r1` 的 JSON 是后续统一复测，由同一个 vLLM Pod
作为客户端，分别通过 Kubernetes Service 访问 vLLM 和 SGLang。后续横向参考
应以 `-r1` 结果为准。

统一复测均使用同一 Tokenizer 和 seed，`request-rate=inf`、
`temperature=0`、`ignore-eos=true`。表中 TTFT、TPOT 和 E2EL 均为毫秒。

32K 理论最大并发从 Off 的 6.70× 依次降到 5.63×、5.06× 和 4.61×。因此当前
配置优先推荐 MTP2：C8 已取得 +48.4% 吞吐和更低 TPOT；MTP3 在 C8 只比 MTP2
再快 2.9%，但 p95 TPOT、TTFT 和 E2EL 均略有回退。若工作负载长期稳定在 C4，
且目标是最大化吞吐，则 MTP3 仍有约 9.9% 的额外收益。
