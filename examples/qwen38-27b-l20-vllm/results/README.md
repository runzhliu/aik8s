# vLLM 实测结果（2026-08-15）

环境：单张 NVIDIA L20（46,068 MiB）、`vllm/vllm-openai:v0.26.0-cu129`、
Qwen3.8-27B-FP8、TP=1、32K、FP8 KV、MTP Off。

本目录保留两组口径：不带 `-r1` 的 JSON 是最初从服务 Pod 通过 loopback
得到的 day0 基线；带 `-r1` 的 JSON 是后续统一复测，由同一个 vLLM Pod
作为客户端，分别通过 Kubernetes Service 访问 vLLM 和 SGLang。后续横向参考
应以 `-r1` 结果为准。

统一复测均使用同一 Tokenizer 和 seed，`request-rate=inf`、
`temperature=0`、`ignore-eos=true`。表中 TTFT、TPOT 和 E2EL 均为毫秒。

C8 到 C10 的输出吞吐只增加约 1%，现场指标为 8 个运行、2 个等待；当前配置的
短请求吞吐已经在 C8 附近饱和。C10 的 p95 指标由详细时间数组补算，其余表项由
benchmark 直接输出。

发布所需的汇总指标。
